# 다음 실험 계획 — 12

상태: 구현·평가 완료. 아래는 평가 전 계획과 정상 진단 후 고정한 명세이며 [결과 보고서](EXPERIMENT12.md)에 결과를 기록했다.

## 질문과 근거

같은 관계 상태라도 진입한 이전 상태에 따라 정상 체류 시간을 나누면, 상태별 pooled 길이 모델의 한계를 줄일 수 있는가?

실험 11은 최종 AUROC/AP를 낮추고 정상 오탐 260프레임을 추가했다. 정상 FIT에서 상태 2 길이 중앙값은 1→2 진입 시 134프레임, 3→2 진입 시 18프레임이었다. 두 맥락의 완결 FIT 구간은 18/16개다. 이 차이는 조건화 실험의 근거이며 오류 원인이나 개선 효과의 확정은 아니다.

## 다음 실행 범위

1. 특징·관계 phase·Visual·기존 전이·max 결합을 유지하고 체류 길이의 조건만 바꾼다. 경과 시간은 실험 11처럼 관측된 진입 이후의 원본 프레임 차이이며, 진입 맥락은 현재 체류 구간에 들어오기 직전의 관측 상태다. 매 프레임의 직전 상태와 혼동하지 않는다.
2. 실험 12는 `(진입 이전 상태, 현재 상태)`별 엄격 유효 완결 정상 길이를 사용한다. 최소 완결 구간 10개를 유지한다. 지원 부족 맥락, 시작 경계, 관계 누락 후 진입 미확정은 기존 전이로 fallback하고, 짧은/생략 단계 모델이나 threshold 탐색은 추가하지 않는다.
3. `12_support` 대조군을 함께 둔다. 실험 12와 **동일한 유효 마스크**를 사용하지만 길이 분포는 실험 11의 상태별 pooled 정상 길이로 유지한다. 이를 통해 지원 부족 맥락을 제외한 효과와 길이 조건화 자체의 효과를 분리한다. 원본 11도 비교 기준으로 남긴다.
4. raw survival 수식·유효 정상 calibration의 전역 midrank CDF·체류/전이 max·최종 Visual/Process max·정상 q99를 유지한다. 각 설정의 정상 reference와 최종 q99는 해당 점수로 다시 적합한다. 정상 support와 가용성을 진단한 뒤 테스트 평가 전 설정을 고정한다.
5. 두 설정의 특징·기존 branch·유효 마스크가 동일한지 검증한다. 전체 AUROC/AP, 정상 오탐/이상 recall, 맥락별 추가/손실 경보, 체류 가용성, GT 구간 미탐·지연을 평가한다. 적은 정상 calibration 영상과 진입 맥락별 길이 변동을 한계로 남긴다.
6. 실험 12가 좋아져도 `12_support`와 차이가 없으면 맥락별 길이 모델의 기여라고 주장하지 않는다. 불리한 결과도 보고한다. 오래 지속되는 테스트 정상이나 잘못 추정된 phase가 이 변경으로 해결된다는 보장은 없다.

R03은 개발 장면이다. 의미 상태 정확도·novelty·일반화는 별도 근거가 필요하며 다음 추천순 3개는 이 결과를 보고 다시 정한다.

## 정상 진단 후 고정한 실행 명세

- 지원 맥락은 0→1, 1→2, 2→3, 3→2이고 FIT 완결 구간은 각각 17/18/23/16개다. 최소 10개 규칙을 유지했다.
- 두 설정의 유효 관측은 FIT 1,923/3,142, calibration 424/703으로 같다. calibration의 무효 raw를 CDF에 넣지 않는다.
- 12는 맥락별 길이, 12_support는 동일 마스크에서 실험 11의 상태별 길이를 사용한다. 두 설정의 정상 reference와 q99는 각각 재적합한다. 짧은/생략 단계 점수와 결합 가중치 탐색은 추가하지 않는다.
- 테스트 평가 전에 설정·코드·특징 hash를 기록했다. 진입 맥락은 체류 구간 전체에서 고정하고 누락 시 버린다.
