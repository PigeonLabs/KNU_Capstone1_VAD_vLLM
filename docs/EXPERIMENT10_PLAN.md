# 다음 실험 계획 — 10

상태: 실험 09 결과에서 선택한 다음 단계. 아직 구현·실행하지 않았다.

## 질문과 근거

외형 점수를 공정 점수로 낮추지 않는 고정 결합이 상태 유지 구간의 탐지를 회복하면서 추가 공정 증거를 제공하는가?

실험 09에서 상태 유지 Process는 0.4375~0.4905였다. 평균 결합은 Visual=1이어도 0.7188~0.7453이므로 정상 q99 0.9580을 넘지 못했다. 실제 상태 유지 이상 4,884프레임에서 탐지가 없었다. Combined AUROC 0.7108도 Visual 0.7330보다 낮았다. 이 결과에 따라 결합 구조를 분리 검증한다.

## 실행 범위

1. 실험 09의 모든 특징·관계 phase·외형 PCA·전이·이전 상태별 정상 보정·분할·sampling을 유지한다. 상태 체류 시간이나 검출 개선을 동시에 추가하지 않는다.
2. 실험 10의 결합만 `max(Visual, Process)`로 변경한다. 대조군 `10_visual`은 동일한 Visual 점수를 최종 점수로 사용한다. 기존 실험 09 평균 결합, max 결합, Visual 단독을 같은 장면에서 비교한다. 여러 가중치나 결합 함수를 탐색하지 않는다.
3. 각 최종 점수마다 동일 정상 calibration에서 q99를 정하고 strict `>`를 유지한다. max 점수가 Visual보다 작지 않다는 수학적 성질은 보장하지만, 재보정한 threshold에서 recall이 나아진다는 보장은 없다. 동점·상단 포화 빈도도 기록한다.
4. 두 branch의 점수와 정상 reference가 보존됐는지 검증한다. 전체 AUROC/AP, 정상 오탐/이상 recall, 상태 유지/변경별 오류, GT 구간별 미탐·지연을 비교한다. Visual 단독 대비 추가 탐지와 추가 오탐을 함께 기록한다.
5. max가 Visual 단독보다 나쁘면 그 결과도 보고한다. 모델 채택을 테스트 최고점만으로 결정하지 않는다. 이번 단계는 결합 기여를 확인하는 개발 비교이며 추가 novelty나 일반화 입증은 아니다.

결과를 보고 다음 추천순 3개를 갱신한다. R01/R03은 개발 장면으로 취급하고 최종 논문 주제나 전체 후속 실험을 미리 확정하지 않는다.
