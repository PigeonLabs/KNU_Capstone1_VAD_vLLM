# 다음 실험 계획 — 22

상태: 실험 21 결과에서 선택한 다음 단계. 아직 구현·실행하지 않았다.

## 질문과 근거

관측된 정상 FIT를 선택하는 효과가 관측 정보에 따른 표본 구성 때문인가, 같은 수만큼 임의로 줄여도 얻는 효과인가?

실험 21에서 A(관측 FIT 제한)는 B를 끈 조건에서 Combined AUROC +0.011016, 정상 오탐 −70프레임이었고, B를 켠 조건에서도 +0.007702/−51프레임이었다. 하지만 정상 학습 수, PCA rank, phase 0 bank의 지원 부족 제거도 동시에 변했다. 이 차이를 통제하지 않고 관측 정보의 가치를 주장할 수 없다.

## 비교 구성

이번에는 B를 끈 상태로 고정해 학습 표본 선택만 비교한다. 기존 18(전체 FIT)과 21_fit(관측 FIT)을 참고/직접 기준으로 두고, **count-matched random FIT** 다섯 개를 새로 평가한다. 선택 seed는 실행 전 `[0,1,2,3,4]`로 고정하며 최고 seed를 선택하지 않는다. 이는 특징/관계 모델의 기존 seed 42를 변경하는 것이 아니라 정상 bank 표본을 뽑는 별도 seed다.

## 고정할 변경과 평가 순서

1. 기존 실험 18/21의 모든 특징·객체·track·관계 phase·관측 mask·공정 모델을 재사용한다. 새 VLM/검출/CLIP/관계 추론은 없다. FIT 20/calibration 5/test 19, PCA 95%/최대 rank 32/최소 10개, 역할 전체 CDF, max 결합, q99/strict `>`, sampling 4프레임/causal hold를 유지한다.
2. 역할×phase별 전체 정상 FIT 관측을 일정한 시퀀스/배열 순서로 모은다. 목표 개수는 해당 bank의 `relation_valid=True` FIT 관측 수다. 각 seed에서 같은 bank의 전체 FIT 관측 중 목표 개수만큼 **균등·비복원 추출**한다. seed별로 bank key를 정렬해 순회하고 선택 인덱스도 정렬해 저장한다.
3. 선택 단위는 global/crop 특징 관측이다. 같은 frame에 여러 객체 후보가 있으면 각각 별도 관측이며 역할별 bank는 독립적으로 선택한다. 관측 mask는 목표 개수 산정에만 사용하고, 추출될 특정 관측을 선호하는 데 쓰지 않는다. 테스트·calibration 특징은 선택 모집단에 포함하지 않는다.
4. 모든 역할의 pooled bank는 여전히 전체 정상 FIT 특징을 한 번씩 사용한다. phase 0은 목표 수가 3개라 관측 FIT 구성과 동일하게 최소 10개를 충족하지 못한다. 같은 bank 수·표본 수·지원 부족 경로가 나와야 한다. variance 규칙에 따라 PCA rank는 달라질 수 있으므로 별도 보고하고 같게 강제하지 않는다.
5. B는 다섯 구성 모두 끈다. 미관측 상태에서도 기존 초기/이전 phase를 사용하되 phase bank 지원이 부족할 때의 기존 pooled fallback은 유지한다. 전이/체류와 모든 process score는 기준 구성과 같아야 한다. 각 구성의 외형 residual로 정상 역할 CDF와 q99를 다시 적합한다.
6. 설정·선택 seed·입력·코드를 정상 실행 전에 고정한다. 다섯 구성과 기존 18/21_fit에 동일한 정상 영상 leave-one-out을 적용하고 모든 reference/q99에서 제외 영상을 빼도록 검증한다. 정상 오탐을 보고하되 seed를 선택하거나 표본을 다시 뽑지 않는다.
7. 전체 정상 calibration으로 finite/포화/q99 가능성을 확인한다. 실패한 seed도 포함해 보고하고 그 seed의 기준을 수정하지 않는다. 가능성을 통과한 다섯 고정 구성을 테스트 19개 영상에서 각각 한 번 평가한다. 기존 18/21_fit 결과는 재현 검증한다.
8. 각 seed별 정상 holdout, 전체/관측별 AUROC/AP·오탐/recall·구간 탐지/지연을 모두 공개한다. 평균·범위는 표본 선택 민감도로 제시하고 영상 독립성에 대한 신뢰구간이나 유의성으로 해석하지 않는다. 관측 FIT가 무작위 범위를 벗어나더라도 선택 정보의 효용에 대한 제한된 근거이며 semantic 정확도/novelty 증명이 아니다.
9. bank별 모집단/목표/선택 개수, 중복 없는 선택, normal FIT 출처, 고정 seed 재현, pooled 보존, 같은 지원 부족 bank, process 불변성, holdout 비누출을 검사한다. 선택 인덱스와 feature hash는 로컬 artifact에 보존하고 공개 결과에는 재현용 설정·hash·집계만 남긴다. 테스트 점수/라벨/전체 지표도 재구성한다.

이 실험은 관계 관측 정보를 무시한 동일 크기 대조를 추가하는 것이다. 역할·phase 자체는 기존 추정치를 사용하므로 실제 의미 품질의 정답을 얻는 것은 아니다. 정상 관측 간 상관과 R04 반복 개발 한계도 남는다. 다섯 random 구성을 독립 데이터셋으로 취급하지 않고, 결과를 본 뒤 다음 추천순 3개를 갱신한다.
