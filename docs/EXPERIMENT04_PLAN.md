# 다음 실험 계획 — 04

상태: 실행 완료. 아래는 테스트 평가 전에 고정한 계획이며, [실험 04 결과](EXPERIMENT04.md)에 실제 결과와 한계를 별도로 기록했다.

## 질문

제품 관측이 충분해진 상태에서, 정상 궤적의 프레임당 진행량이 현재 phase 전이 빈도에 없는 이상 신호를 제공하는가?

## 실험 03의 근거

직접 phase 관측률은 94.75%, Visual AUROC는 0.6514였지만 Process AUROC는 0.5388, Combined는 0.5814였다. 같은 phase에 머무는 전이만으로 제품의 진행·정지를 구분하기 어렵다. 이 구조적 한계를 검증하는 것이 다음 우선 과제다. 테스트 점수로 가중치를 탐색하는 실험으로 바꾸지 않는다.

## 다음 실행 순서

1. 실험 03 정상 FIT 캐시에서 인접 sampled 시점의 동일 product track 쌍을 진단한다. 유효 쌍의 수, phase별 진행량 분포, ID 단절과 미관측 비율을 기록한다. 좌표 변화량을 원본 프레임 간격으로 나누며 FPS를 가정하지 않는다.
2. 이 진단에 근거해 정상 phase별 진행량 모델과 유효 관측 처리 규칙을 정하고 테스트 평가 전에 설정을 기록한다. 첫 관측·track 변경·관측 누락을 정지 속도 0으로 대체하지 않는다.
3. 실험 03의 detector, ROI, 전체 프레임/crop 특징, phase map, 분할, sampling을 고정한다. 진행량 신호의 단독 진단과 파이프라인에 넣었을 때의 차이를 보고하고, 결합 규칙을 테스트 라벨로 조정하지 않는다.
4. 동일 R01 범위에서 AUROC/AP, 정상 보정 임계값의 오탐/recall, 진행량 관측률을 비교한다. 개선·악화 모두 보고하고 업로드한 뒤 다음 후보 순위를 갱신한다.

이 계획은 실험 04만 대상으로 한다. 전체 후속 실험의 개수·주제는 고정하지 않는다. R01의 반복 관찰 결과는 개발용이며 최종 성능 검증으로 사용하지 않는다.


## 정상 FIT 진단 후 고정한 실행 명세

정상 FIT 진행량 유효 비율은 1,432/1,556=92.03%, phase별 표본은 423/486/523이다. 이 정상 데이터 진단 후, 테스트 지표를 계산하기 전에 다음을 고정한다.

- 진행량 = 인접 sampled 시점의 동일 선택 track 중심 이동량 / 원본 프레임 인덱스 차이. 이동축은 실험 03의 x축을 유지한다.
- phase별 정상 median과 `max(1.4826*MAD, 1e-6)`로 절대 편차를 정규화한다. 최소 10개 미만 phase는 pooled normal 모델을 사용한다.
- 별도 정상 calibration의 유효 진행량 residual로 midrank percentile을 구한다. 미관측 sentinel 0은 적합·보정에서 제외한다.
- 유효 진행량이 있으면 `process = max(기존 전이 percentile, 진행량 percentile)`로 결합한다. 없으면 기존 전이 점수를 유지한다. 최종 `0.5*visual + 0.5*process`는 유지한다.
- 정상 calibration에서 새 Combined q99를 계산한다. 기존 visual 점수·전이 점수는 동일한지 검사한다. 추가 가중치나 threshold 탐색은 하지 않는다.
- 진행량 단독 지표는 유효 시점에 한정된 진단으로 별도 보고하며, 전체 프레임의 주 지표와 직접 동일 조건이라고 해석하지 않는다.

이 max 규칙은 미리 고정한 OR 결합이며 통계적으로 최적이라는 주장이 아니다. 한 프레임 간격의 bbox jitter와 ID 오류에 민감할 수 있다.
