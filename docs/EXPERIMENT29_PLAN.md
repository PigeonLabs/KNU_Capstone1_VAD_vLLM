# 다음 실험 계획 — 29

상태: 실험 28 결과에서 선택한 다음 단계. 아직 구현·실행하지 않았다.

## 질문과 근거

정상 전이 3→2의 coverage 부족은 영상별 공정 차이와 희소 전이 때문인가, 객체/track·관계 특징의 변동 때문인가? 현재 저장 정보로 어느 정도까지 구분할 수 있는가?

실험 28에서 정상 영상 02의 `[152,156)`, `[376,380)` 전이가 상태 CDF 최대를 넘으면서 오탐이 8프레임 늘었다. 해당 reference는 88개/4개 영상이지만 관측 전이 3→2를 포함하지 못했다. test 경보는 그대로이고 ranking은 소폭 악화돼, 추가적인 보정식 변경보다 관측 근거와 영상별 coverage 확인을 우선한다.

## 이번 진단 단계의 구현 범위

1. 파이프라인에 **정상 전이 근거 추적 출력**을 추가한다. 정상 FIT 20 + calibration 5개, 고정된 실험 27/28 입력과 분할을 사용한다. 점수·phase·mask·모델·임계값은 바꾸지 않는다. 테스트 영상/라벨을 새로 열거나 테스트 성능을 재평가하지 않는다.
2. 전체/연속 관측 전이의 4×4 count, 전이별 고유 영상 수와 영상별 count를 FIT/calibration에서 분리한다. 정상 calibration leave-one-video-out마다 사라지는 전이, count≥10이어도 특정 목적 상태가 없는 이전 상태 reference, global fallback을 구분한다. 상태 support와 edge coverage를 혼동하지 않는다.
3. 각 전이에서 이전/현재 source frame·phase·relation mask·객체 역할/track/bbox·관계 특징과 사용 가능한 semantic margin/검증 정보를 연결하는 trace를 만든다. 캐시에 없는 필드는 null/미측정으로 명시한다. 필요하면 저장 모델과 정상 특징으로 관계 descriptor/phase 입력을 재구성하고 기존 phase와 일치 여부를 확인한다. 객체 검출기나 VLM을 재학습/재추론하지 않는다.
4. 정상 반례를 시각 점검할 로컬 contact sheet를 만든다. 영상 02의 두 반례는 반드시 포함한다. 나머지 정상 관측 3→2 사례를 영상/프레임 순으로 영상별 round-robin하여 총 최대 24개 선택한다. 대조 사례는 이전 상태 3에서 다른 상태로 향하는 관측 전이(자기 유지 포함)를 같은 방식으로 최대 24개 선택한다. 각 사례는 이전·현재와 가능한 경우 다음 sampled frame을 보여준다. 다음 frame은 사후 설명에만 사용하며 모델/점수 입력으로 쓰지 않는다.
5. 선택 규칙·case ID·원본 frame 좌표·분할·선택 이유를 먼저 저장하고 시각 점검한다. 목적 표집이므로 accuracy/recall을 추정하지 않는다. 자동 trace와 시각 관찰을 분리하고 의미가 모호하면 미확정으로 남긴다. 모델의 phase ID는 semantic 공정 정답으로 바꾸지 않는다.
6. 원본/크롭/contact sheet는 로컬 artifacts에만 저장한다. GitHub에는 추적 코드·설정·집계·사례 ID/좌표·한계·보고서를 올린다. 원본 데이터·가중치·특징 캐시·서버 로그 업로드 금지 원칙을 유지한다.

## 검증과 산출물

- 실행 전 입력/계획/코드/hash를 동결하고, 전이 count와 고유 영상 수를 독립 반복문으로 재검증한다. 첫 sample·누락·영상 경계가 올바르게 처리되는지 검사한다.
- 정상 25개 파일의 trace와 원본 source frame 경로 대응을 확인한다. 모든 수치 집계는 전체 정상 범위, 시각 검토는 선정 사례 범위로 구분한다.
- 저장된 정상 점수·reference·특징 hash가 바뀌지 않았는지 확인한다. 관련 테스트와 재현 명령을 기록한다.
- 새 AUROC/AP나 성능 향상은 보고하지 않는다. 구현한 진단 기능, 영상별 전이 coverage, 실제로 확인한 반례와 미확정 항목을 표/필요한 그래프로 보고한다.
- 결과·의의·보완점·추천순 3개를 정리해 GitHub에 업로드한다. 다음 scoring/관측 개선은 이번 감사 결과에 따라 선택하며 미리 확정하지 않는다.

## 한계

정상-only 진단은 이상 탐지 효용을 평가하지 않는다. 시각 점검은 연구용 탐색 메모이며 독립 semantic/bbox 주석이 아니다. 관측 mask와 잠재 phase의 정확도, 원본 녹화 그룹 독립성, 실제 시간은 확인할 수 없다. 반례의 원인을 하나로 확정할 수 없으면 불확실성을 그대로 보고한다.
