# 다음 실험 계획 — 21

상태: 실험 20 결과에서 선택한 다음 단계. 아직 구현·실행하지 않았다.

## 질문과 근거

관측 정보를 외형 학습에 반영하는 것과 추론에서 pooled fallback을 사용하는 것 중 무엇이 오탐 감소와 이상 경보 손실에 기여했는가? 두 요소의 결합이 필요한가?

실험 19는 두 변경을 함께 적용해 정상 오탐 −91/이상 탐지 −69프레임이었다. 실험 20의 경로별 CDF는 미관측 이상 탐지를 순 60개 늘렸지만 관측 탐지 56개를 잃어 전체 순증가는 4개였고 정상 holdout 오탐은 44→68개로 악화됐다. 보정 복잡도를 더하기 전에 외형 모델 학습/선택의 효과를 분리한다. 실험 20 CDF는 기본 구성으로 승격하지 않는다.

이는 후속 실험 전체 일정이 아니라 이번 실험 한 번의 구성 요소 분리 대조다. 두 기존 셀은 저장된 결과를 재현 검증하고 두 새 셀을 평가한다. 성능이 좋은 셀만 보고하지 않는다.

## 고정 조건과 평가 순서

1. 실험 18/19의 동일 bbox·global/crop 특징·track·문장 embedding·temporal gate margin·관계 phase·`relation_valid`를 재사용한다. VLM/검출기/CLIP 재추론이나 관계 군집 재적합은 없다. R04 FIT 20/calibration 5/test 19, seed 42, sampling 4프레임, causal hold를 유지한다.
2. A는 phase별 PCA에 넣는 FIT 관측만 제한한다. 역할별 pooled PCA는 모든 정상 FIT 특징을 한 번씩 사용한다. B는 calibration과 테스트에서 현재 관계가 미관측인 경우에만 pooled PCA로 보낸다. A/B는 별도 설정으로 구분하며 process phase는 수정하지 않는다.
3. B가 꺼져도 phase bank가 존재하지 않으면 기존 최소 지원 fallback은 작동한다. 예를 들어 21_fit의 phase 0은 관측 FIT가 3개뿐이어서 bank가 없으므로 pooled로 처리된다. 이를 B에 의한 명시적 fallback과 구분해 집계한다.
4. PCA 95%/최대 rank 32/최소 10개, 공정 전이·체류·보정, max 결합, 역할 전체 외형 CDF, q99/strict `>`를 유지한다. `appearance_route_calibration`은 네 셀 모두 끈다. 각 셀의 정상 외형 residual로 CDF와 q99를 각각 다시 적합하며 임계값을 같게 강제하지 않는다.
5. 코드·입력·설정을 정상 실행 전에 고정한다. 네 셀 모두 동일 정상 calibration 영상 5개를 하나씩 제외하는 holdout을 수행한다. PCA는 정상 FIT만으로 고정하고 제외 영상은 모든 reference/q99에서 빠진다. 정상 전체/관측별 오탐, 실제 bank 경로 및 지원 부족, fold별 q99/포화와 reference 수를 보고한다. holdout에 맞춰 설정을 튜닝하지 않는다.
6. 전체 정상 calibration에서 각 셀의 경보 가능성을 검사한다. 점수 비정상 또는 q99=1이면 해당 셀의 실패를 기록하며 임계값을 수정하지 않는다. 정상 검사를 통과한 두 새 셀을 테스트 19개 영상에서 각각 한 번 평가한다. 기존 18/19 모델·점수는 저장값과 일치해야 한다.
7. 전체 및 고정 관측/미관측 subset의 AUROC/AP·정상 오탐·이상 recall·GT 구간/지연을 네 셀 모두 비교한다. A의 차이를 B 고정 조건별로, B의 차이를 A 고정 조건별로 제시하고 추가/제거 경보와 bank 사용량을 연결한다. 보정 재적합까지 포함한 구성 효과이며 단일 seed의 기술 통계로 인과적 일반화·유의성을 주장하지 않는다.
8. 검사 항목은 A/B 독립 동작, calibration/추론의 동일 경로, 원본 phase/mask 보존, 최소 지원 fallback, pooled 단일 삽입, 정상 holdout 비누출이다. 실제 데이터에서 21_fit PCA=19 PCA, 21_infer PCA=18 PCA, 모든 pooled PCA/공정 점수 보존, 기존 셀의 점수 재현, 새 셀의 reference·지표 재구성을 검증한다.

이 대조는 학부 캡스톤의 파이프라인 구성 근거를 강화하기 위한 것이다. 새 셀의 점수가 좋아도 그 자체로 novelty가 되지 않는다. R04는 반복 개발 장면이고 별도 객체/phase GT는 없다. 다음 개선은 네 셀의 결과를 함께 본 뒤 추천순 3개로 새로 정한다.
