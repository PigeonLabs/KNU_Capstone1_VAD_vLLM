# 다음 실험 계획 — 05

상태: 실행 완료. 아래는 실행 전에 고정한 계획이며 [실험 05 결과](EXPERIMENT05.md)에 실제 결과와 한계를 기록했다.

## 질문과 근거

단일 sampling 간격 대신 여러 연속 관측에 걸친 진행량으로, 짧은 정상 경보 변동을 줄이면서 진행 이상 신호를 보존할 수 있는가?

실험 04의 Combined AUROC/AP와 recall은 상승했지만 정상 오탐률은 9.95%였다. 오탐 경보 구간 41개 중 30개가 4프레임 이하였으며 bbox/단일 간격의 순간 변동에 민감할 가능성이 있다. 원인이 bbox jitter라고 확정한 것은 아니다. 실제 이상과 겹치는 경보 구간에도 짧은 구간이 있으므로 탐지 지연과 손실을 함께 검증해야 한다.

## 고정할 변경

- `v_t = (x_t - x_(t-3)) / (frame_t - frame_(t-3))`를 사용한다. 4프레임 sampling에서 3개 간격, 즉 12프레임에 걸친 변위다. 현재와 과거의 **연속된 4개 관측**이 모두 유효하고 같은 track일 때만 사용한다.
- 첫 구간·track 변경·중간 누락은 invalid로 유지하고 기존 전이 점수로 fallback한다. 미래 위치 보간이나 경보 길이를 보고 사후 삭제하는 처리는 하지 않는다.
- 정상 FIT/calibration에서 새 진행량 모델을 적합·보정한다. detector/ROI/특징/phase/median-MAD 규칙/max 결합/최종 가중치/q99 규칙은 실험 04와 동일하다.
- 시간 간격을 여러 값으로 탐색하지 않는다. 이 한 후보의 AUROC/AP·오탐/recall, 진행량 유효 관측률, 경보 구간 길이 및 GT 이상 구간의 첫 경보 지연을 비교한다. 지연은 원본 프레임 단위이며 미탐 이벤트를 제외하고 평균만 내지 않는다.
- 테스트 라벨은 결과 진단에만 사용하고 규칙·threshold 선택에 사용하지 않는다. R01은 반복 개발 장면이며 결과에 따라 다음 우선순위를 다시 정한다.

이 문서는 실험 05만 계획한다. 더 긴 간격이 반드시 유리하다고 가정하지 않으며 짧은 이상 손실 또는 관측 가용성 저하가 발생하면 그대로 보고한다.
