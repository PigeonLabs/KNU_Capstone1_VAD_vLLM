# 보류된 기존 실험 40 안 — 체류 학습 정렬

상태: 미실행·보류. 사용자의 공유 시각 표현 학습 지시에 따라 실험40은 EXPERIMENT40_PLAN.md의 A~D 비교로 전환했다. 아래 내용은 이전 제안의 기록이며 실행 지시가 아니다.

## 질문과 근거

체류 학습 자료의 관측 정의를 추론과 같은 객체 쌍의 완결 episode로 정렬하면, 현재 정상 데이터에서 어떤 문맥을 지원할 수 있고 지원 부족은 탐지에 어떤 영향을 주는가?

실험39는 추론 gate로 근거 없는144프레임을 차단했으나 학습 분포는 legacy0→1/1→2의13/16 runs로 유지했다. 같은 쌍의 완결은9/4이고 2→1도4개다. 어느 문맥도 기존 최소 지원10을 충족하지 않는다. 현재 체류 독자 FP13/TP19는 같은 쌍에서도 남고 추가 구간은0이다. 학습 자료 정의와 지원 여부부터 일관되게 만드는 것이 목적이다.

## 변경 하나: 동일 쌍 완결 학습과 명시적 미지원 상태

- control은 실험39 gated hold/pool/age다. 변경군은 `extract_dwell_episodes`의 `status=complete`인 정상 FIT episode만 체류 분포 적합에 쓴다. 관측된 진입·내부 연속·관측된 이탈이 모두 같은 선택 anchor/target track 쌍이어야 한다.
- 상태별/진입 문맥별 duration은 같은 strict 자료에서 만들고, 실제 사용하는 entry-context lognormal 분포의 최소 완결 수10·sigma floor.05는 그대로다. 미래 이탈은 정상 학습 표본의 완결 판정에만 쓰며, 추론은39의 현재/과거 근거만 사용한다.
- 문맥에 지원이 없으면 분포를 만들지 않는다. 전체 문맥이 미지원이어도 학습 오류로 중단하거나 legacy 자료로 돌아가지 않고 **체류 branch unavailable**을 명시한다. raw/gated 체류 점수0·valid false·미지원 사유를 기록하고 외형/전이 경로는 계속 작동한다. 이는 정상성의 증거가 아니다.
- 현재 FIT에서는 문맥별9/4/4로 체류가 모두 미지원일 것으로 예상한다. 이 예상과 실제 집계를 대조한다. 지원을9로 낮추거나 calibration을 FIT에 추가하지 않는다. 우측 검열/진입 미확인은 진단에 보존하되 완결로 대체하거나 이번 분포에 넣지 않는다.
- 검출/선택/feature/asinh phase/PCA/rank/외형 초기 gate·정책/전이·실제 CDF는 고정한다. 체류 FIT 표본과 그에 따른 지원/분포만 바꾸고 정상 calibration으로 q99를 재계산한다. 새 VLM/검출/encoder 호출, 검열 분포 적합, phase 재학습은 동시에 하지 않는다.

## 정상 검증과 동결

1. 코드·계획·설정·기존 정상 입력을 동결하고 test/label 접근을 차단한다.
2. 진입·내부·이탈의 쌍 교체, 누락, 영상 끝 검열, 진입 미확인, 빈 지원, 충분한 지원이 있는 합성 정상 자료의 lognormal 파라미터/점수를 검사한다. 지원이0인 데이터만으로 성공 테스트를 끝내지 않는다.
3. 원시 duration을 독립적으로 재구성해 문맥별 수·길이·영상 수를 대조하고 미지원 상태를 보고한다. control은39 모델/예측을 재현하고 변경군의 PCA/전이/외형/실제 CDF를 보존한다.
4. 정상5영상 leave-one-video-out으로 held-out을 보정에서 제외한다. 유한/범위·q99<1과 외형/전이 사용 가능성을 확인한다. 체류 unavailable은 별도의 명시적 상태로 남기며, 이를 지원된 체류 모델로 간주하지 않는다.
5. 체류 미지원 시 process가 기존 gated transition과, combined가 max(visual, gated transition)과 정확히 같은지 검사한다. 자신의 q99와 고정 control q99 대조로 체류 제거와 재보정 효과를 구분한다. 정상 검증/모델/q99를 동결한 뒤 test를 연다.

## 테스트와 해석

R04 test19영상/8,154 frames에서 AUROC/AP·정상 FPR/이상 recall·구간 gained/lost·조건부 지연을 보고한다. 원래 체류 독자 FP13/TP19에 생기는 변화를 확인하되 그 test 값으로 지원 기준이나 분포를 고르지 않는다. branch unavailable과 경보0/정상 판정을 구분하고, 가용성·차단 정상/이상·외형/전이-only 동등성을 공개한다.

완결이 부족하면 이 실험은 새 체류 추정기의 성능 입증이 아니라 근거 정의에 맞는 학습 가능성과 미지원 동작의 검증이다. 검열 모형이나 정상 자료 추가 여부는 그 결과를 보고 다음에 결정한다. 단일 R04 반복 개발로 novelty·일반화·통계적 유의성을 주장하지 않는다. 완료 후 결과·의의·보완점·추천순3개를 기록하고 업로드한다.
