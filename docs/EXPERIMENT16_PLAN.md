# 다음 실험 계획 — 16

상태: 실행 완료. 아래는 평가 전 계획이며, [실험 16 결과](EXPERIMENT16.md)에 경보 복구와 체류 추가 기여 부재를 기록했다.

## 질문과 근거

완결 정상 길이의 경험적 최댓값을 넘으면 모두 1이 되는 체류 점수 대신 연속 꼬리를 가진 점수를 쓰면, 정상 q99가 닫힌 상한에 고정되는 실패를 줄이면서 유용한 이상 신호를 유지할 수 있는가?

실험 15의 R04에서는 정상 calibration 영상 08의 경과 시간 64~80프레임이 1→2 FIT 최대 60을 넘어 5개 점수가 1로 포화됐다. 전체 482개 중 1.037%이며 최종 q99=1, 경보 0, GT 이상 26개 전부 미탐이었다. AUROC는 0.7061로 높아졌으나 운영 가능한 경보가 아니었다. 임계값 비교 연산이나 test 기반 threshold 조정으로 이 실패를 숨기지 않는다.

## 이번 변경과 고정 조건

1. 실험 15의 R04 특징·객체 역할·관계 phase·정상 분할·지원 맥락·체류 유효 마스크·Visual/기존 전이·max 결합을 그대로 유지한다. 정상 grounding 오류도 그대로 남기고 별도 한계로 보고한다. 이번 실험에서 detector 프롬프트를 함께 바꾸지 않는다.
2. 지원 맥락별 동일한 FIT 완결 길이 D에 `log(D)`의 평균 mu와 표준편차 sigma(ddof=0)를 적합한다. 수치적 최소 sigma는 0.05로 미리 고정한다. 관측 경과 시간 a>0의 점수는 `Phi((log(a)-mu)/sigma)`, a=0은 0이다. 미래 종료 길이를 입력으로 쓰지 않고, calibration 경과 시간 CDF로 다시 변환하지 않는다.
3. 이는 **lognormal 분포 가정을 둔 연속 체류 점수**이며 실제 정상 길이가 이 분포를 따른다고 확인한 것은 아니다. 기존 empirical score와 support를 동일하게 두고 점수 표현만 비교한다. 29/26개의 완결 구간에 대한 근사이며 독립 영상 수와 구분한다. 표준 분포 모형 자체를 novelty로 주장하지 않는다.
4. 정상 FIT 모델·정상 calibration 점수만으로 먼저 finite 여부, 1에 포화된 표본, q99<1 여부를 검사해 경보 가능성을 명시한다. 부동소수점 CDF도 극단적인 입력에서 1이 될 수 있으므로 완전한 포화 방지를 보장하지 않는다. q99=1이면 실패로 기록하고 epsilon·`>=`·임의 파라미터 재선택으로 통과시키지 않는다.
5. 정상 calibration으로 기존 방식의 reference와 q99를 적합한다. 평가 전 설정/코드/입력 hash를 동결하고 테스트 점수 계산 뒤 라벨을 읽는다. R04는 이미 관찰한 개발 장면이며 독립 테스트가 아니다.
6. 실험 15 체류와 15_base(체류 없음)를 기준으로 전체 AUROC/AP·오탐/recall, 포화 비율·경보 가능성, GT 구간 미탐/지연, 추가/제거 경보와 유효 구간을 비교한다. 경보 복구만을 성공으로 보지 않고 정상 오탐 증가와 기존 외형 탐지 손실을 함께 확인한다.

R04 결과로 설정을 고른 뒤 다른 장면 성능을 주장하지 않는다. 새 장면 추가·grounding 수정·미관측 phase 처리·여러 분포/seed 탐색은 이번 실험에 섞지 않는다. 결과에 따라 추천순 3개를 갱신한다.
