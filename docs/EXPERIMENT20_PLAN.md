# 다음 실험 계획 — 20

상태: 실험 19 결과에서 선택한 다음 단계. 아직 구현·실행하지 않았다.

## 질문과 근거

관계 관측을 반영한 외형 모델에서 phase bank와 pooled bank의 residual을 같은 정상 CDF에 섞는 대신, 실제 bank 경로별로 보정하면 점수의 비교 가능성과 미관측 구간 탐지를 개선할 수 있는가?

실험 19는 정상 오탐을 379→288프레임으로 줄였지만 이상 탐지도 670→601개로 줄었다. 미관측 구간에서 정상 경보 −72/이상 경보 −124였고 GT 구간 하나를 놓쳤다. 정상 calibration의 판재 raw residual 99% 분위는 관측 0.07117 / 미관측 0.04933이며, 기존 CDF 후에는 0.99271 / 0.96329다. 이는 경로별 보정을 검토할 근거이며 원인으로 입증된 것은 아니다. 정상 표본을 나누면 꼬리 보정이 더 불안정해질 수 있다.

## 고정할 변경과 평가 순서

1. 실험 19의 모든 특징·관측 mask·관계 phase·외형 PCA·전이/체류 모델을 그대로 재사용한다. 이미지 추론이나 관계 재적합을 하지 않는다. normal FIT/calibration 분할, seed 42, sampling 4프레임, max 결합, q99/strict `>`와 causal hold를 유지한다.
2. 외형 residual의 정상 calibration CDF만 **역할×실제 선택 bank 종류 `{phase, pooled}`**로 구분한다. latent phase 번호별로 더 나누지 않는다. 관계 관측 여부만으로 경로를 정하지 않고, 지원 부족으로 pooled bank를 선택한 관측도 pooled 경로에 포함한다.
3. 각 경로에 정상 calibration 특징 관측 50개 이상·서로 다른 정상 시퀀스 2개 이상이 있을 때만 경로별 CDF를 쓴다. 부족하면 기존 역할 전체 CDF로 fallback한다. 두 기준은 이번 계획에서 고정한 실용적 지원 guard이며 독립 표본 수나 q99 신뢰도 보장이 아니다. 실제 표본 수·영상 수·CDF 해상도를 공개하고 기준을 탐색하지 않는다.
4. 우선 정상 calibration 영상 5개에 대해 leave-one-video-out을 수행한다. 정상 FIT로 만든 모든 모델은 고정하고, 나머지 4개 calibration 영상으로 외형/공정 보정과 최종 q99를 각각 적합한다. 제외 영상은 어떤 보정 reference나 q99에도 포함하지 않는다. 동일 fold에서 기존 역할 전체 CDF와 새 경로별 CDF를 비교하며 전이/체류 보정 경로는 두 구성에서 같아야 한다.
5. 제외 정상 영상의 전체·관측/미관측·실제 bank 경로별 경보 수/비율, 영상별 q99, finite/1 포화, 지원 부족 fallback을 보고한다. sampled 관측과 dense 원본 프레임의 분모를 구분한다. 결과가 나쁘더라도 지원 기준·문장·분할·가중치를 조정해 유리한 구성을 선택하지 않는다.
6. 다음으로 전체 정상 calibration 5개로 고정한 후보를 적합하고 경보 가능성을 검사한다. 점수가 비정상이거나 q99=1이면 실패를 기록하고 임계값 조정으로 테스트를 진행하지 않는다. 가능성이 확인되면 해당 설정을 그대로 동결해 R04 테스트 19개를 한 번 평가한다.
7. 실험 19와 전체 AUROC/AP·정상 오탐/이상 recall·GT 구간/지연을 비교한다. 같은 mask의 관측/미관측 지표·추가/제거 경보·실제 bank 경로 사용량을 함께 보고한다. q99가 달라질 수 있으므로 같다고 가정하거나 테스트 FPR을 맞추지 않는다.
8. 테스트 전에 경로 결정, 최소 관측/영상 지원 fallback, calibration 영상 제외, 상수 residual 동률 처리, 추론·보정의 동일 경로를 검사한다. 실제 데이터에서 PCA/raw residual/관계 mask/공정 점수의 보존, 정상 holdout 비누출, 각 reference와 예측의 재구성, 지표 재계산을 확인한다.

미관측 경보 손실은 pooled PCA의 낮은 특이성 때문일 수도 있으며, CDF 변경으로 복원할 수 있다는 보장은 없다. phase 지원 부족으로 생긴 pooled 경로와 관계 누락에 따른 pooled 경로도 분포가 다를 수 있다. 이 차이는 진단하되 이번에는 경로를 추가 분할하지 않는다. 정상 시퀀스는 독립 녹화 그룹임이 확인되지 않았고 R04는 반복 개발 장면이다. 성능 개선만으로 novelty·일반화를 주장하지 않는다. 다음 추천순 3개는 이 결과 이후 갱신한다.
