# 다음 실험 계획 — 15

상태: 실행 완료. 아래는 평가 전 계획이며, [실험 15 결과](EXPERIMENT15.md)에 grounding 오류와 q99 포화에 따른 경보 불능을 기록했다.

## 질문과 근거

R03에서 만든 객체 관계 기반 파이프라인을 새로운 실제 장면 R04의 정상 자료에 적합했을 때, 관측과 정상 모델이 성립하며 체류 모듈이 기여하는가?

실험 14는 알려진 정상 holdout의 추가 오탐 40프레임을 제거했으나, R03 테스트에서는 체류 없는 실험 10보다 정상 오탐 308프레임을 추가하고 이상 32프레임만 더 탐지했다. 새 이상 구간은 찾지 못했다. R03 안에서 다시 점수를 조정하기보다 장면별 재적합 절차와 모듈의 적용 범위를 검증한다. 성능을 보고 장면을 고르는 방식으로 진행하지 않는다. R04는 Stage 00에서 라벨 길이 문제가 확인되지 않은 다른 실제 장면이며, 같은 IPAD 자료이므로 외부 독립 검증으로 부르지 않는다.

## 실행 범위

1. Stage 00의 R04 정상 FIT/calibration 분할과 seed 42를 유지한다. R04 테스트 내용이나 점수로 역할·모델·threshold를 고르지 않는다.
2. 기존 normal-only discovery와 동일하게 정상 FIT 첫 2개 영상의 6개씩 프레임을 로컬 Qwen에 제공한다. 사용자 설정인 Qwen3.8 Q8, 요청당 context 65536, temperature 0.2, 모든 가중치 GPU, reasoning on, parallel 1 및 나머지 기본값을 유지하고 실제 서버 설정을 검증한다.
3. 정상 영상에서 관측 가능한 두 역할을 관계 anchor/target으로 지정하고 근거를 기록한다. 역할 선택은 정상 FIT 시각 증거에 한정한다. 적절한 두 역할이 없거나 검출/관계 support가 성립하지 않으면 적용 실패로 기록하며 테스트를 보고 객체·phase를 반복 수정하지 않는다.
4. GroundingDINO+tracking, frozen CLIP, 4프레임 sampling, 관계 descriptor/normal FIT KMeans K=4, PCA 설정, 이전 상태별 전이 보정, max 결합을 유지한다. 단위/시간축은 원본 프레임 인덱스다. R03에서 학습한 중심·PCA·길이를 R04에 그대로 가져오지 않고 R04 정상 FIT로 재적합한다. 이는 가중치의 zero-shot 전이가 아니라 **고정한 절차의 장면별 적용**이다.
5. 동일한 R04 특징·관계 phase를 공유하는 두 구성을 미리 고정한다: 체류 없는 실험 10 구성, 완결 FIT percentile을 쓰는 실험 14 구성. 체류의 최소 완결 구간 10, 미관측 진입/누락/지원 부족 abstention도 유지한다. Visual 단독 ranking은 branch 지표로 함께 보고한다. 테스트 결과로 유리한 구성만 남기지 않는다.
6. 정상 FIT의 역할/관계 관측과 군집 support를 기록한 뒤 설정·코드·입력 출처를 동결한다. 정상 calibration으로 reference/q99를 별도 적합하고 테스트 라벨은 각 영상의 점수 계산 후 평가에만 사용한다. 관측 실패나 체류 미지원은 숨기지 않는다.

7. 두 구성의 AUROC/AP, 정상 q99 오탐률·recall, GT 구간 탐지/미탐·조건부 지연, 추가/제거 경보, 관계/체류 가용성을 비교한다. phase/bbox GT가 없으면 정확도는 주장하지 않는다. 정상 q99는 새 정상 영상에서 1% 오탐의 보장이 아니다.

평가 전 절차 명확화: 기존 평가기의 실제 순서인 점수 계산 → 라벨 로드 → 결과 저장을 위 6번에 반영했다. 정상 FIT의 정성 확인에서 역할 오검출이 보이더라도 수치상 관계/체류 support가 충분하면 동결한 출력으로 후단 비교를 수행하고, 의미상 grounding 실패를 별도로 보고한다. 성공한 공정 관측으로 해석하지 않으며, 프롬프트를 고쳐 유리한 결과만 남기지 않는다.

새 장면에서의 성능 상승이나 novelty를 미리 주장하지 않는다. 추가 재보정·새 모듈·여러 seed 탐색은 이번 변경에 섞지 않는다. 실험 15 결과로 다음 추천순 3개를 갱신한다.
