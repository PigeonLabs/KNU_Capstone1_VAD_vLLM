# 다음 실험 계획 — 14

상태: 실행 완료. 아래는 평가 전 계획이며, [실험 14 결과](EXPERIMENT14.md)에 정상 holdout과 R03 개발 테스트의 절충을 기록했다.

## 질문과 근거

FIT에서 관측한 완결 정상 길이 분포를 직접 사용하면, 관측 경과 시간을 다시 calibration하는 과정에서 정상 support가 왜곡되는 문제를 줄일 수 있는가?

실험 13의 정상 holdout 22에서 1→2 구간 길이는 232프레임이고 FIT 최대 정상 길이는 244였다. 하지만 보정 영상 세 개의 같은 구간은 모두 180프레임이어서 관측 경과 시간 192~228에 체류 percentile=1이 됐고 오탐 40프레임이 추가됐다. 이 결과로 완료 길이와 관측 경과 시간의 보정 단위를 다시 검증한다.

## 실행 범위

1. 실험 12의 특징·관계 phase·진입 맥락별 완결 FIT 길이·유효 마스크·Visual/기존 전이·max 결합을 유지한다. 맥락 support 최소 10개, 시작/누락/미지원 시 abstention도 같다.
2. 체류 점수만 각 맥락의 **완결 FIT 길이 D에 대한 현재 관측 경과 시간 a의 empirical midrank percentile**로 바꾼다. 현재의 `raw survival → 유효 calibration 경과 시간 CDF` 단계를 대체한다. 큰 경과 시간이 높은 점수를 얻고, 미래 종료 길이를 추론 입력으로 쓰지 않는다. 별도의 test 가중치나 꼬리 threshold를 탐색하지 않는다.
3. Visual/전이의 정상 reference와 최종 q99는 기존 정상 calibration으로 적합한다. 체류 자체의 점수 reference는 FIT 완결 길이이며, calibration 경과 시간으로 다시 percentile을 계산하지 않는다. 어디에 FIT와 calibration이 쓰이는지 별도 기록한다.
4. 먼저 실험 13과 같은 네 정상 holdout에서 실험 12와 비교한다. 정상 영상 22의 추가 경보뿐 아니라 전체 영상의 오탐·support·fallback을 확인한다. 이 정상 검증 결과로 함수를 재선택하지 않고 고정한 설정의 R03 개발 테스트 결과도 평가한다.
5. 기존 branch·유효 마스크·시간 인과성을 검증하고 AUROC/AP, 정상 오탐/이상 recall, GT 구간 미탐·지연과 체류 가용성을 보고한다. 정상 support를 더 보존하는 대신 이상 민감도가 낮아지는지 확인한다.
6. 맥락별 완결 길이는 16~23개로 percentile 해상도가 낮고 같은 영상의 여러 구간이 독립은 아니다. 관측 최대 길이 안의 이상을 놓칠 수 있으며 정상의 미래 변동을 보장하지 않는다. 네 정상 holdout과 R03 테스트 모두 개발에 사용한 자료라는 한계를 유지한다.

이 변경의 성공이나 novelty는 미리 주장하지 않는다. 결과에 따라 다음 추천순 3개를 갱신한다.
