# 다음 실험 계획 — 23

상태: 실험 22 결과에서 선택한 다음 단계. 아직 구현·실행하지 않았다.

## 질문과 근거

표본 수뿐 아니라 PCA rank도 같게 맞추었을 때, 관측 FIT와 무작위 FIT 사이의 외형 점수 차이가 유지되는가?

실험 22에서 관측 FIT는 Visual AUROC 0.7001로 무작위 5개 구성의 0.6889–0.6955보다 높고 정상 오탐도 적었다. 하지만 Combined AUROC는 무작위 범위 안이고, 탐지 구간은 13개 대 16–18개로 적었다. 같은 수의 정상 표본으로 학습했어도 global phase 2의 rank는 관측 30/무작위 31–32, role 1 phase 2는 관측 31/무작위 29–32였다. 남은 모델 용량 차이를 통제한 비교가 필요하다.

## 이번에만 구체화하는 변경

1. 실험 21_fit과 실험 22의 seed 0–4를 그대로 사용한다. 정상 FIT 20 / calibration 5 / R04 테스트 19, 특징·역할·track·관계 phase·관측 mask·표본 선택 인덱스를 보존한다. 무작위 표본을 다시 추출하거나 seed를 추가·선택하지 않는다. B는 계속 끈다.
2. 각 지원되는 역할×phase bank의 공통 rank를 **여섯 기존 정상 FIT 모델 rank의 최솟값**으로 정한다. 규칙은 calibration/테스트 점수와 무관하다. 실험 22의 정상 감사에서 global phase 2는 30, role 1 phase 2는 29, 나머지 지원 phase bank는 32다. 입력을 재검증해 이 값과 같음을 확인한다. phase 0은 표본 3개로 계속 미지원이다.
3. 각 모델의 평균과 선택된 정상 표본을 유지하고 기존 PCA basis의 앞쪽 공통 rank만 사용한다. 새 방향·재가중치·다른 표본은 추가하지 않는다. pooled bank는 여섯 구성 모두 이미 동일하므로 변경하지 않는다. 학습 표본 수·phase bank 지원·실제 추론 경로도 보존한다. 이 대조는 기존 95% 규칙의 자동 rank 선택을 공통 rank로 제한하는 변경이며, 모든 bank가 95%를 설명한다고 주장하지 않는다.
4. 여섯 구성 `23_obs`, `23_s0`~`23_s4` 모두를 공개한다. 각 구성의 기존 가변 rank 버전도 짝지어 비교한다. 변경이 없는 bank는 평균/basis/residual이 동일해야 하며, rank가 줄어든 bank는 같은 입력에서 raw residual이 감소하지 않아야 한다. 최종 보정 점수/경보는 CDF 재적합으로 단조 변화가 보장되지 않는다.
5. 공정 전이·체류와 relation mask는 바꾸지 않는다. 역할 전체 CDF·정상 q99/strict `>`·max 결합·causal hold를 유지하고 각 구성에서 정상 calibration을 다시 적합한다. 새 VLM·검출기·CLIP 추론은 없다.
6. 코드·설정·공통 rank·선택 인덱스 hash를 정상 calibration 전에 고정한다. 동일 정상 영상 leave-one-out 5 fold를 적용하고 모든 reference/q99의 제외 영상 비누출을 검사한다. 전체 정상 보정의 finite/[0,1]/q99<1 가능성 검사도 기록한다. 실패한 구성은 숨기거나 임계값을 조정하지 않는다.
7. 정상 검사 후 여섯 고정 구성을 테스트에서 각각 한 번 평가한다. 전체/관측·미관측 subset의 Visual·Combined AUROC/AP, 정상 holdout, FP/recall, 구간 탐지·지연, 각 구성의 q99를 모두 보고한다. seed 평균·범위는 표본 선택 민감도이고 신뢰구간·유의성 검정이 아니다.
8. 기존 대비 rank만 바뀌었는지 독립적으로 검증하고 정상 bank·reference·전체 테스트 예측/원본 라벨·지표를 재구성한다. 모든 seed의 긍정·부정 결과를 포함해 다음 추천순 3개를 다시 결정한다.

관측 표본 선택에 따른 시간적/영상별 구성 차이는 여전히 남는다. 공통 rank 이후 차이가 유지되어도 실제 객체 의미 정확도나 다른 장면 일반화의 증명이 아니다. 반복 관찰한 R04는 개발 데이터로 한정하며 새로운 논문 주제를 고정하지 않는다. 다음 단계 전체를 미리 기획하지 않는다.
