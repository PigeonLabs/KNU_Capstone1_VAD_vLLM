# 다음 실험 계획 — 08

상태: 구현·평가 완료. 아래는 평가 전 계획과 정상 진단 후 고정한 명세이며, [결과 보고서](EXPERIMENT08.md)에 관측 결과를 기록했다.

## 질문과 근거

전체 프레임–텍스트 유사도 대신 지게차–팔레트의 관측 관계를 이용하면, 정상 공정의 구별 가능한 상태를 구성할 수 있는가?

R03에서 carrying phase가 모든 분할에서 0개였고 기본 Process AUROC는 0.4980이다. 지게차 진행량만 추가하면 Combined ranking도 낮아졌다. 다음 단계는 공정 상태의 관측 표현을 바꾸는 것으로, 실험 07 기본 설정을 비교 기준으로 삼고 실패한 진행량 모듈을 동시에 추가하지 않는다.

## 다음 실행 순서

1. 실험 07 정상 FIT 캐시에서 두 역할의 후보 bbox를 진단한다. track 연속성/검출 confidence를 이용한 후보 선택과 상대 위치·겹침·크기 관계의 가용성을 확인한다. 큰 배경 박스가 관계를 오염시키는지 먼저 점검하며 품질 기준이 필요하면 정상 데이터만으로 정하고 기록한다.
2. 정상 FIT 관계 descriptor로 latent state를 구성하는 구체적인 변환·군집 규칙을 정한다. 우선 후보는 상대 중심 좌표, bbox 겹침/크기 비율과 정상 robust scaling이다. 상태 수는 기존 정상 discovery의 4개 후보를 참고하되 의미 상태 정답으로 취급하지 않는다. 정확한 입력·누락 처리·상태 대응 규칙은 정상 진단 후 테스트 평가 전에 고정한다.
3. detector 가중치·기존 bbox/crop/full-frame 특징·분할·sampling을 보존한다. 관계 기반 phase 모듈만 교체하고 그 phase로 외형 subspace·전이·calibration을 다시 적합한다. phase 외형 모델의 변화는 이 변경의 하위 효과로 구분해 기록한다.
4. latent state에 실제 행동 이름을 근거 없이 부여하지 않는다. 정상 시퀀스에서 시간적 순서를 참고하더라도 이를 phase GT로 부르지 않으며, 테스트 시간 인덱스나 미래 프레임을 phase 예측 입력으로 사용하지 않는다. 누락 시 임의 정상 관계를 만들어 넣지 않는다.
5. 상태 support/가용성, AUROC/AP, 정상 오탐/recall 및 구간별 미탐·지연을 함께 비교한다. 상태 점유율이 퍼졌다는 이유만으로 semantic grounding이 성공했다고 결론 내리지 않는다. 이번부터 반복 개선에 사용한 R03은 개발 장면이다.

이 실험의 결과를 보고 다음 추천순 3개를 정한다. 독립 bbox/phase 주석이 없다는 한계는 유지하며 최종 논문 주제나 전체 실험 일정은 미리 고정하지 않는다.


## 정상 FIT 진단 후 고정한 실행 명세

- bbox 선택 상한: 역할별 정상 FIT 로그 면적의 `Q3+1.5*IQR`를 지수 변환(최대 1). 지게차 0.687666, 팔레트 0.106046이다. phase anchor에만 적용하며 외형 branch의 검출은 보존한다. 같은 track을 우선하고 후보 내 confidence 최댓값을 선택한다.
- 관계 descriptor 6개: 팔레트의 상대 중심 x/y(지게차 bbox 크기로 정규화), 로그 면적비, bbox IoU, 지게차 절대 중심 x/y. 마지막 두 값은 같은 상대 관계라도 작업 공간 위치가 다른 경우를 표현한다.
- 현재/과거 최대 3개 유효 descriptor 평균. 관계 누락 시 평균 history를 비우고 이전 phase를 유지하며, 첫 관측 전에는 latent_0이다. 누락 marker는 군집 적합에 넣지 않는다.
- 정상 FIT median/IQR(최소 scale 0.05)로 정규화하고 KMeans 4개, seed 42, n_init 10으로 적합한다. cluster 번호만 정상 FIT의 median 상대 프레임 위치 순으로 정렬한다. 테스트 시간/영상 길이는 inference 입력에 넣지 않는다.
- 상태 이름은 latent_0..3이며 VLM의 idle/carrying 같은 의미를 부여하지 않는다. 기존 4상태 self/next/cycle 전이 penalty의 수치 구조는 유지한다. 이 순서 prior도 검증되지 않은 heuristic이다.
- 정상 FIT 유효 관계 3,136/3,142=99.81%, 유효 군집 표본 1,186/972/747/231이다. 누락 fallback 포함 phase 표본은 1,189/975/747/231이다. 분포가 퍼진 것을 semantic 정확도로 주장하지 않는다.
- 테스트 지표 계산 전에 위 설정을 고정했다. detector/기존 특징/분할/score 결합을 보존하고 phase에 종속된 정상 모델·calibration만 재적합한다. 진행량 모듈은 추가하지 않는다.
