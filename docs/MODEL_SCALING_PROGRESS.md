# 모델 확장·학습·하이퍼파라미터 실험 진행 기록

사용자 목표: 더 큰 모델의 여러 유망 후보를 실제 비교해 선정하고, 변경 모델에 적절한 LoRA/FT를 충분히 수행한다. 검출/표현 특징 수와 시계열 학습 단위 등 하이퍼파라미터를 비교하며, 과적합을 검증한다. 매 단계마다 수행 → 결과·의의·한계·추천순3개 보고 → GitHub 업로드 → 근거 기반 다음 실험 설계를 반복한다.

이 목표는40~43의 완료와 별개다. 아래 미완료 항목이 남아 있는 동안 새 목표를 완료 처리하지 않는다. 전체 실험 조합을 먼저 확정하지 않고 직전 결과에 따라 다음 변경을 선택한다.

| 요구사항 | 현재 근거/상태 |
|---|---|
| 기존 파이프라인/자원/실패 원인 검토 |40~43 보고서 검토, GPU96GB·데이터 디스크 여유 확인. 검출 loss/weak phase agreement와 AD 개선이 불일치 |
| 여러 대형 모델 실제 비교 및 선정 |45 실행·검증 완료:3후보 전체177영상 추론, 정상 proxy로CLIP-L 선정. 큰 frozen 모델의Combined AUROC는.6377~.6398로 Mobile.6584보다 낮음. [결과](EXPERIMENT45.md) |
| 선정한 변경 모델의 LoRA/FT 학습 | 미완료.45결과로46의CLIP-L LoRA/partial/full FT9run·최대60epoch·early stopping 계획 작성. [46 계획](EXPERIMENT46_PLAN.md) |
| 파이프라인의 다른 모델 확장 검토/실험 | 미완료. visual 결과와 detector 병목을 근거로 다음 단일 변경 선택 |
| 특징/검출 수 변경의 실제 비교 | 미완료. 기존 role별 최대3개, PCA rank cap32, pooled crop 특징을 기준으로 무엇을 늘릴지 결과에서 선택 |
| 시계열 학습 단위/하이퍼파라미터 비교 | 미완료. frame index 단위를 유지하며 FPS를 추정하지 않음; causal clip/history 조정은 후속 결과에서 설계 |
| 과적합 점검/충분한 학습 | 이후 학습에서 train/val curve, epoch0 포함 checkpoint 선택, early stopping, seed·유효 표본 수·collapse/teacher drift를 기록할 예정 |
| 단계별 보고/업로드/추천순3개/최종 종합 |45결과·의의·한계·추천순3개·README·46계획 작성. 단계별 업로드 후46실행. 새 목표의 최종 보고는 아직 없음 |

44의 독립 사람 주석/새 녹화 검증은 자료가 없는 미실행 계획으로 유지한다. 기존 데이터로 진행 가능한 개발 실험을 계속하되 이를 독립 확인으로 바꾸어 부르지 않는다. 성능이 하락한 후보나 채택되지 않은 모델도 실행 근거와 함께 남긴다.
