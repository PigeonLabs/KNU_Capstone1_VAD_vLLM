# 다음 실험 계획 — 25

상태: 실험 24 결과에서 선택한 다음 단계. 아직 구현·실행하지 않았다.

## 질문과 근거

관측 누락 처리 규칙을 바꾸어도 정상 보정 reference 자체는 고정되게 만들면, 경로 변경과 보정의 간접 효과를 분리할 수 있는가?

실험 24의 56프레임 제한은 긴 누락 구간의 이상 경보 20프레임을 제거했다. 동시에 외형 bank/raw residual이 바뀌지 않은 관측·짧은 누락 구간에서 정상 19/이상 57프레임의 경보가 추가됐다. q99와 공정 점수도 동일했으므로 이 추가 경보는 역할 전체 CDF에 들어가는 정상 residual 혼합이 달라진 간접 효과다. 정상 holdout 합계는 유지됐지만 테스트 Combined AUROC와 오탐은 악화됐다.

## 이번에만 구체화하는 변경

1. 실험 23_obs / 24_pool / 24_age의 세 경로를 고정한다. 새 구성은 각각 25_hold / 25_pool / 25_age다. FIT 표본·PCA bank·공통 rank·관계 phase/관측 mask·전이/체류·τ=56·프레임 sampling을 모두 보존한다. 원본 세 구성도 재현해 짝지어 비교한다. 특정 경로를 성능 승자로 선택하지 않는다.
2. 정상 calibration의 각 global/crop 특징 관측에 대해 **두 외형 경로를 모두 계산**한다. 첫째는 원본 phase를 요청하는 경로로, 지원되는 phase PCA가 없으면 기존 pooled fallback을 사용한다. 둘째는 해당 역할의 pooled PCA를 직접 요청하는 경로다. 첫째 reference에는 관계 미관측 때의 기존 유지 phase도 포함된다. 두 경로의 normal-only residual을 역할별로 각각 모아 두 CDF를 적합한다. 같은 역할의 두 CDF는 동일한 정상 관측 모집단·시퀀스 순서를 가지며, 각 관측을 reference마다 한 번씩 넣는다.
3. CDF의 이름은 **phase 요청 경로 / pooled 요청 경로**다. 첫째는 최소 지원 fallback을 포함하므로 실제 bank가 언제나 phase라는 뜻이 아니다. 데이터/기능을 임의로 보충하는 것이 아니라 동일 특징을 이미 학습된 두 정상 모델 경로에 통과시킨 결과다. 실제 gate 선택 횟수에 따라 calibration 모집단을 나누지 않는다. 실험 20의 실제 bank 경로별 부분 표본 CDF와 달리, 두 CDF가 각각 전체 정상 calibration 표본을 사용한다.
4. 추론에서는 기존 gate가 phase를 요청하면 첫째 CDF, 명시적 pooled를 요청하면 둘째 CDF를 적용한다. 25_hold는 항상 첫째, 25_pool은 관측 시 첫째/미관측 시 둘째, 25_age는 관측·age≤56에서 첫째/초기 미관측·age>56에서 둘째다. 지원 미달 phase의 fallback도 첫째 요청 경로 정의에 포함한다. 이 경우 실제 raw residual이 pooled와 같더라도 요청 경로 CDF는 달라질 수 있으므로 따로 기록한다.
5. 세 새 구성의 두 역할별 CDF는 같은 calibration 입력을 쓰면 정확히 같아야 한다. 따라서 **같은 요청 경로를 쓰는 특징의 보정 점수는 gate 종류와 무관하게 같아야 한다.** max object/global 결합, 공정 CDF는 유지한다. 정상 q99는 각 구성의 결합 정상 점수로 따로 적합한다. q99가 달라질 수 있으므로 점수 불변과 경보 불변을 혼동하지 않고 임계값 효과를 별도 보고한다.
6. 코드·입력·두 경로 정의를 정상 실행 전에 고정한다. 정상 calibration 5개 영상 leave-one-out에서 제외 영상은 양쪽 reference와 공정 reference/q99에서 모두 제외한다. FIT의 τ는 모든 fold에서 고정한다. 전체 정상 보정의 finite/[0,1]/포화/q99<1을 확인하고 실패 시 임계값을 바꾸지 않으며 실패 구성도 보고한다. q99=1 경보 불능 가능성을 숨기지 않는다.
7. 가용성 검사를 통과한 사전 고정 구성들을 각각 한 번 테스트한다. 전체 Visual/Combined AUROC/AP·FP/recall·구간/지연, 관측/초기/짧은/긴 누락 subset과 실제 지원 fallback을 보고한다. 같은 경로의 점수 불변 검증, 관측 상태의 간접 점수 변경 제거 여부, 정상 holdout·새 오탐/미탐을 함께 평가한다. 결과를 본 뒤 새 경로·quantile을 선택하지 않는다.
8. 두 reference의 표본 수·순서·정상 출처와 holdout 제외를 독립 재구성한다. PCA/공정/raw residual 불변, 모든 역할/객체별 보정과 최종 점수·원본 라벨·지표를 검증한다. 실제 crop reference 모집단은 frame 수와 다를 수 있으므로 관측 수를 따로 보고한다.

이 변경은 gate에 따른 정상 reference 혼합을 제거하는 설계다. 정상 calibration이 적고, 요청 경로별 분포가 모든 상태에서 잘 보정된다는 보장은 없다. 나쁜 객체/phase 입력이나 장면 일반화 문제도 해결하지 못한다. 성능이 악화되어도 실패와 분기 효과를 공개하며 후속 전체 계획을 미리 확정하지 않는다.
