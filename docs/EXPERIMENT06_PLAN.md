# 다음 실험 계획 — 06

상태: 실행 완료. 아래는 실행 전 고정 계획이며 [실험 06 결과](EXPERIMENT06.md)에 실제 결과와 한계를 기록했다.

## 질문

진행량 모델의 phase 조건화가 필요한가, 아니면 하나의 pooled 정상 모델로 단순화할 수 있는가?

실험 04·05에서 진행량과 시간 간격의 효과는 확인했지만 phase 조건의 기여는 분리하지 않았다. 새로운 파이프라인 구현의 논문 근거를 위해, 복잡성을 늘리는 것뿐 아니라 어떤 구성 요소가 필요한지 확인한다.

## 고정 비교

- 실험 05의 12프레임 진행량, 유효 마스크, detector/ROI, 전체 프레임·객체 특징, phase 배열, 정상 fit/calibration 분할을 그대로 사용한다.
- **진행량 모델만** phase별 median/MAD에서 모든 phase를 합친 단일 median/MAD로 교체한다. 외형 PCA의 phase 조건화와 전이 점수는 유지한다. 따라서 전체 파이프라인에서 phase가 불필요한지를 검증하는 실험은 아니다.
- 표준화 residual의 정상 calibration percentile, max 공정 결합, 0.5/0.5 최종 결합, 정상 q99 정책은 동일하게 적용한다. threshold는 각 모델의 정상 calibration에서 계산한다.
- 설정·가중치를 test 성능으로 탐색하지 않는다. AUROC/AP·오탐/recall·GT 구간 탐지 지연 및 모델 수를 비교한다. 필요하면 phase별 오류 분포를 결과 진단으로만 기록한다.
- 성능이 비슷하면 더 단순한 진행량 모델을 채택할 후보로 본다. phase 조건화가 유리하면 그 근거를 기록하되 단일 R01 개발 결과로 일반화 또는 novelty를 주장하지 않는다.

이 실험 결과를 보고 다음 추천순 3개를 다시 정한다. 미사용 장면 검증과 초기/누락 처리 후보를 확정된 전체 실험 일정으로 만들지 않는다.
