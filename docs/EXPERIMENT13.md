# 실험 13 — 정상 영상 단위 보정 holdout 검증

## 이번 실험 결과

**보정에서 제외한 정상 영상의 오탐률은 체류 모듈 없이 1.568%, 체류 모듈 포함 시 2.994%였다.** 체류 모델 세 가지는 동일한 경보를 냈고, 추가 오탐 40프레임은 모두 정상 영상 22에서 발생했다. 이 구간의 길이는 정상 FIT 범위 안에 있었지만 세 영상으로 만든 보정 reference의 범위를 넘어 체류 percentile이 1로 포화됐다.

이번은 새로운 이상탐지 성능 실험이 아니라 **정상 보정 검증 절차를 추가한 실험**이다. 정상 영상만 평가하므로 anomaly AUROC/AP·recall·이상 구간 지연은 계산 대상이 아니며, 이전 테스트 결과를 이번 성능으로 재사용하지 않았다.

### 질문·비교·분할

실험 12에서 길이 모델이 그대로인 맥락도 다른 맥락의 raw 변화 때문에 보정 점수가 달라졌다. 작은 calibration 집합으로 만든 reference와 q99가 보정에서 제외한 다른 정상 영상에서도 안정적인지 검증했다.

- R03의 정상 FIT 18개와 해당 FIT로 적합한 표현·PCA·전이·체류 길이 모델을 고정했다. seed 42와 기존 모델 설정은 그대로다.
- 기존 calibration 영상 07/08/15/22 중 하나를 제외하는 4개 fold를 구성했다. 각 fold는 나머지 3개로 **모든 Visual/process/dwell reference와 최종 q99**를 적합하고 제외한 정상 영상 1개를 평가한다.
- 설정 10(체류 없음), 11(상태별 체류), 12_support(동일 support 대조), 12(진입별 체류)를 비교했다. 총 16개 실행이며, 각 설정이 평가한 고유 영상은 동일한 4개, 원본 프레임은 2,806개다. 이를 16개 독립 영상으로 세지 않는다.
- 4프레임 sampling, 이전 sampled 점수 유지, 최종 max 결합과 strict `>` q99 경보를 유지했다. 모델·threshold·새 CDF·가중치를 탐색하지 않았다.
- 이번 실행과 검증은 `training_*.npz` 중 명시한 정상 영상만 읽는다. `testing` 특징이나 anomaly 라벨을 열지 않았다. 새 VLM/GPU 특징 추출은 없으며 실행 시간·운용 지연은 측정하지 않았다.

### FIT 정상 범위 안에서 발생한 추가 오탐

추가 오탐 40프레임은 모두 영상 22의 1→2 진입 구간이다. 상태별/지원 대조/진입별 체류 모델의 경보 마스크가 모두 같았고 다른 정상 영상에서는 체류가 추가 경보를 만들지 않았다.

| 정상 길이/관측 | 원본 프레임 기준 |
|---|---|
| FIT 1→2 완결 길이 (18개) | 최소 16, 최대 244 |
| 보정 영상 07/08/15의 같은 완결 구간 | 각각 180 |
| 제외 영상 22의 완결 구간 | 232 |
| 추가 경보가 시작·끝난 sampled 경과 시간 | 192~228, 4프레임 간격 10개 |
| 해당 추가 구간의 체류 percentile | 모두 1 |

232는 정상 FIT 범위 안이고 추가 경보 시점의 경과 시간도 모두 244 이하이다. 그러나 이 시점의 raw 점수는 세 보정 영상의 raw 최댓값보다 높아 공유 empirical CDF에서 모두 1이 됐다. **완결 정상 길이로 학습한 범위와 관측 중 경과 시간으로 다시 보정한 범위가 일치하지 않는 반례**다. 모든 체류 오탐의 원인이 같다는 증거는 아니다.

### 작은 support와 fallback

영상 07을 제외하면 이전 상태 3의 정상 보정 전이는 9개, 영상 08을 제외하면 7개뿐이다. 최소 10개 기준에 따라 각각 평가 영상의 7/9개 sampled 전이가 기존 전역 reference로 fallback했다. 각 영상 첫 sample의 fallback 1개는 이 수치와 별도다. 네 모델에 공통으로 발생하며 체류 모델만의 문제가 아니다.

진입별 체류의 정상 reference 표본은 fold별 315/314/330/313개지만 모두 3개 영상에서 나온 상관된 관측이다. 많은 프레임 수가 정상 영상의 다양성이나 독립 표본 수를 대신하지 않는다.

## 결과의 의의

FIT 표현과 모델을 고정하고, 모든 보정 reference에서 평가 영상을 제외하는 검증 절차를 구현했다. 단순히 보정 데이터의 경보율이 약 1%라는 사실만으로 다른 정상 영상의 안정성을 판단할 수 없음을 확인했다.

테스트 이상 라벨을 사용하지 않고도 정상 FIT 범위 안의 긴 구간이 calibration 꼬리 밖으로 밀려 오탐되는 구체적 사례를 얻었다. 다음 보정 변경을 설계할 근거이며, 새로운 이상탐지 알고리즘의 novelty나 성능 향상 자체를 입증한 결과는 아니다.

## 보완할 점

- 정상 영상 4개뿐이며 추가 오탐은 한 영상에 집중된다. 미래 정상 분포의 오탐률이나 통계적 유의성을 일반화할 수 없다.
- 이 4개 영상은 이전 실험에서 calibration으로 사용됐다. 이번 fold의 reference 계산에서는 제외했지만, 프로젝트 전체에서 처음 보는 최종 검증 집합은 아니다. 향후 개선에도 이 결과를 사용하므로 개발 진단으로 남긴다.
- 체류 추가 없는 모델도 정상 오탐률이 1.568%이며, 07 영상은 2.90%다. 체류 보정만 고쳐 모든 정상 오탐을 해결할 수 없다.
- 완료 길이와 관측 경과 시간은 서로 다른 통계량이다. 새 보정이 정상 support를 보존하더라도 이상 민감도를 낮출 수 있어 후속 실험에서 trade-off를 확인해야 한다.
- 원본 녹화 그룹 독립성, 관계 phase의 의미 GT·bbox 품질은 미확인이다. 다른 장면의 라벨 정렬 미해결과 FPS 부재도 그대로이며 전체 IPAD/최종 독립 테스트를 대체하지 않는다.

## 출처·누수 점검·검증

40개 테스트가 통과했다. 제외 영상의 feature/phase를 크게 바꿔도 모든 reference와 q99가 변하지 않는지 검사했다. 실제 16개 fold의 reference·점수·q99·오탐 수와 집계를 재구성했으며, FIT 모델 fingerprint가 fold마다 보존됨을 확인했다. 공통 Visual/전이 branch 및 맥락 비교군의 유효 마스크도 일치했다.

VLM 객체 discovery의 원본 영상은 정상 FIT의 01/02였다. 정상 22개 영상에서 검출·tracking·외형 특징이 실험 07 캐시와 같음을 확인했고, 관계 모델을 FIT 18개로만 재적합했다. 저장 모델 대비 중심의 최대 차이는 부동소수점 수준인 1.11e-16이었으며 명시한 절대 허용오차 1e-12 이내였다. 위치/scale은 정확히 같았고, 정상 22개 영상의 phase·관측 마스크·관계 descriptor는 모두 정확히 재현됐다. 원본 녹화 그룹 또는 사전학습 데이터의 독립성까지 증명한 것은 아니다.

각 fold의 모델·reference·보정/평가 점수는 로컬 artifacts에 보존하고, 공개 저장소에는 설정·집계·진단·보고서만 업로드한다.

```bash
export PYTHONPATH=src
export MPLCONFIGDIR=.cache/matplotlib
.venv/bin/python scripts/audit_normal_provenance.py
.venv/bin/python scripts/evaluate_normal_holdout.py
.venv/bin/python scripts/validate_normal_holdout.py
.venv/bin/python scripts/plot_normal_holdout.py
.venv/bin/python -m pytest -q
```

원본 평가 전 hash는 원본 실행 기준이다. 재실행 환경에 따른 부동소수점 진단 차이나 코드 변경이 있으면 새 provenance를 기록하고 원본 평가 전 기록을 덮어쓰지 않는다.
