# 다음 실험 계획 — 11

상태: 실험 10 결과에서 선택한 다음 단계. 아직 구현·실행하지 않았다.

## 질문과 근거

관측된 상태 진입 이후의 정상 체류 시간으로, 전이 점수가 놓치는 오래 지속되는 구간에 추가 이상 신호를 만들 수 있는가?

실험 10은 평균 결합의 억제를 해소했지만 Visual 단독 대비 AUROC 차이가 0.0009에 그쳤고 추가 탐지 GT 구간은 없었다. 기존 전이는 self-transition이 계속되면 동일한 점수만 낸다. 정상 FIT 진단에서 상태 1/2/3의 유효 내부 완결 구간은 17/36/25개였고, 상태 0은 대부분 영상 경계에 걸리며 내부 구간 4개는 4~8프레임에 불과했다.

## 다음 실행 범위

1. 실험 10의 객체 특징·관계 phase·외형 모델·기존 전이 및 보정·max 결합을 유지한다. 체류 시간 신호만 추가하며 detector·상태 순서·결합 가중치를 함께 바꾸지 않는다.
2. 먼저 정상 FIT에서 관측된 진입과 종료, 구간 전체 및 인접 관측의 relation_valid를 검사한다. 영상 시작/끝 경계와 누락으로 완전히 관측되지 않은 구간을 완결 정상 길이로 취급하지 않는다. 상태별 완결 유효 구간이 최소 10개일 때만 적합하고 부족한 상태는 pooled 대체 없이 abstain한다. 엄격 기준 적용 후 실제 support를 기록한다.
3. 현재 시점의 경과 시간은 관측된 상태 진입 이후 원본 프레임 차이로 계산한다. 영상 첫 구간은 진입 미관측으로 abstain한다. 관계 누락 후에는 유효한 새 진입이 확인될 때까지 abstain해 보간한 phase로 체류 시간을 이어 붙이지 않는다. 미래 종료 시점이나 전체 테스트 길이는 입력으로 사용하지 않는다.
4. 우선 후보 raw 점수는 완결 정상 길이 D와 현재 경과 시간 a의 smoothed survival `-log((1 + count(D >= a)) / (1 + n))`다. 긴 체류만 다루며 짧은/생략 단계 이상은 이번 범위에서 모델링하지 않는다. 정상 FIT/calibration 가용성과 점수 분포를 진단한 후 테스트 평가 전에 정확한 명세를 고정한다.
5. 유효한 체류 점수만 정상 calibration에서 보정하고, 유효 시 기존 Process와 max로 합친다. 무효 시 기존 Process를 그대로 사용한다. 최종 Visual/Process max와 정상 q99 규칙은 유지하되 새 점수에서 q99를 다시 적합한다. 테스트 라벨로 기준이나 결합을 선택하지 않는다.
6. 기존 Visual·전이 보존, 경계·누락 처리·인과성·상태별 support를 검증한다. AUROC/AP, 정상 오탐/이상 recall, 상태 유지/전환 오류, 체류 가용성, GT 구간 미탐·지연을 보고한다. 상태 0 및 영상 시작부터 존재하는 이상은 체류 모듈의 한계로 명시한다.

이번은 개발 장면 R03의 구성 요소 검증이다. 군집 지속 시간을 실제 행동 시간 정답으로 부르지 않으며, 결과를 보고 다음 추천순 3개를 갱신한다. 최종 논문 주제나 모든 후속 실험을 미리 확정하지 않는다.
