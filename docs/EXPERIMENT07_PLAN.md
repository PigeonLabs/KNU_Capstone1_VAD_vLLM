대상은 **R03**이다. R01 이후 미사용 실제 장면을 번호순으로 검토했을 때 R02는 라벨 길이 불일치가 남아 있고, R03은 Stage 00에서 테스트 라벨 길이가 모두 일치했다. 테스트 성능이나 anomaly 길이를 보고 장면을 고르지 않았다.

- 정상 영상 22개/15,346프레임: 기존 고정 split의 FIT 18개, calibration 4개 사용.
- 테스트 영상 17개/12,005프레임: 정합성은 source frame index 기준이며 FPS는 확인되지 않았다.
- R03의 테스트 특징·지표를 아직 파이프라인 개발에 사용하지 않았다. 실행 후 이를 반복 개선에 사용하면 최종 독립 검증 장면이라고 부르지 않는다.
