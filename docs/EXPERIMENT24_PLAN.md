# 다음 실험 계획 — 24

상태: 실험 23 결과에서 선택한 다음 단계. 아직 구현·실행하지 않았다.

## 질문과 근거

짧은 관계 관측 누락에는 이전 phase를 유지하고 긴 누락에는 pooled bank를 사용하면, 무기한 유지/즉시 전환 사이의 차이를 설명하고 개선할 수 있는가?

실험 23은 표본 수와 rank를 맞춰도 관측 FIT의 외형 ranking·오탐 장점과 구간 미탐의 상충을 남겼다. 관측 FIT는 13/26 구간을 탐지했고, 테스트 global 2,047 samples 중 미관측 641개 가운데 471개는 이전/초기 phase bank를 계속 사용했다. 이 경로는 누락 지속 길이를 구분하지 않는다. 기존 실험 21의 즉시 pooled 전환은 미관측 이상 경보를 줄이는 동시에 역할 CDF를 통해 관측 상태의 경보도 바꿨다.

## 이번에만 구체화하는 변경

1. 통제 기준은 실험 23_obs다. 관측 FIT 표본·공통 rank·pooled bank·관계 phase·role/track·전이/체류를 고정한다. 이 선택은 관측 기반 추론 경로를 분리해 검증하기 위한 기준이며 종합적인 성능 승자 채택이 아니다. R04 FIT 20/calibration 5/test 19, normal-only 학습, 역할 전체 CDF, q99/strict `>`, max 결합, 4프레임 sampling/causal hold를 유지한다.
2. 비교 구성은 세 개다: 기존 **23_obs**(미관측 phase 무기한 유지), **24_pool**(모든 미관측에서 즉시 pooled), **24_age**(초기 미관측 또는 마지막 관측 이후 나이가 정상 기준을 초과하면 pooled). 두 새 구성의 학습 bank는 23_obs와 완전히 같아야 한다. 지원 부족에 의한 기존 fallback도 유지한다.
3. 유지 기준 τ는 정상 FIT의 완결된 관계 누락 구간만으로 정한다. 구간 `[s,e)`의 `relation_valid`가 모두 false이고 바로 앞 `s-1`과 뒤 `e`가 true인 경우만 사용한다. 길이는 `source_frame_index[e] - source_frame_index[s]`로 정의한다. 영상 시작/끝의 잘린 구간은 제외하고 개수·길이를 따로 보고한다. FIT 전체의 **구간 단위 90분위수(method='higher')**를 하나의 전역 τ로 고정한다. 구간별 동일 가중치이며 프레임으로 재가중하지 않는다. 완결 구간이 없으면 임의 τ를 만들지 않고 가용성 실패로 보고한다.
4. 추론에서는 시퀀스마다 마지막 유효 관측 인덱스를 초기화한다. 관측 시 현재 phase를 사용하고 나이를 0으로 둔다. 미관측이면 `현재 인덱스 - 마지막 유효 관측 인덱스`를 나이로 사용해 **age≤τ는 이전 phase, age>τ는 pooled**로 보낸다. 아직 유효 관측이 없으면 처음부터 pooled다. 미래 관측·테스트 영상 전체 길이는 사용하지 않는다. τ의 학습에는 정상 FIT의 완결 구간을 사용하되 온라인 추론에서는 미래에 재관측될지 알지 못한다.
5. τ/학습 구간·코드·설정·입력 hash를 정상 calibration 이전에 고정한다. calibration도 동일한 인과적 경로를 적용하고 각 구성의 역할 CDF/q99를 다시 적합한다. 공정 점수·기존 phase 배열은 바꾸지 않는다. route-specific CDF나 새 검출/CLIP/VLM 추론은 추가하지 않는다.
6. 동일 정상 영상 leave-one-out 5 fold와 전체 calibration 가능성 검사를 먼저 수행한다. τ는 FIT 전용이라 모든 fold에서 고정이며, 제외 정상 영상은 모든 CDF/reference/q99에서 빠져야 한다. 실패한 구성·포화도 숨기지 않으며 τ/임계값을 결과에 맞춰 변경하지 않는다.
7. 정상 검사가 완료되면 사전 고정한 두 새 구성을 각각 한 번 테스트한다. 전체 Visual/Combined AUROC/AP·FP/recall·구간 탐지/지연과 함께 관측, 초기 미관측, 0<age≤τ, age>τ를 같은 mask로 나눠 지표/경보를 보고한다. 각 subset의 정상/이상 분모와 실제 phase/pooled 사용 횟수를 공개하고, CDF 변화 때문에 관측 subset에도 생기는 간접 효과를 확인한다.
8. τ 경계, 재관측 reset, 시퀀스 reset, 미지원 phase fallback, 미래 프레임 추가 시 과거 경로 불변을 검증한다. bank/공정 불변과 제외 영상 비누출, 기존 기준 재현, 점수·라벨·지표 재구성을 확인한다. 입력 bbox/관계가 잘못된 경우는 이 방식이 고치지 못함을 명시한다.

새 τ를 여러 개 sweep하거나 테스트 라벨로 gate를 고르지 않는다. 90분위수 규칙의 효과가 작거나 부정적이어도 그대로 보고한다. R04 반복 개발 한계·관계/역할 GT 부족·FPS 부재는 유지하며, 후속 전체 실험을 미리 확정하지 않는다.
