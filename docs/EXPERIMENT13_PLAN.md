# 다음 실험 계획 — 13

상태: 실험 12 결과에서 선택한 다음 단계. 아직 구현·실행하지 않았다.

## 질문과 근거

보정에 쓰지 않은 정상 영상에서도 정상 q99와 체류 보정이 안정적인가? 체류 모델의 복잡성을 높이기 전에 정상 영상 단위의 독립 보정 검증 절차를 추가한다.

실험 12에서 같은 0→1 raw도 다른 맥락의 분포 변화로 percentile이 달라졌고 정상 오탐이 늘었다. 현재 calibration은 정상 영상 4개에 한정되며 이 영상에서의 보정 진단은 독립 일반화 증거가 아니다. 다음은 알고리즘을 더 복잡하게 하는 단계보다 정상 검증 절차를 보완하는 실험이다.

## 실행 범위

1. R03 정상 FIT 18개 및 이 FIT로 적합한 객체/관계 phase·PCA·전이·길이 모델은 고정한다. 정상 calibration 영상 07/08/15/22를 하나씩 평가용으로 제외하는 4개 fold를 만든다. 이 분할은 테스트 성능과 무관하게 기존 정상 분할에서 정한다.
2. 각 fold에서 나머지 정상 3개로 **모든** Visual/process/dwell reference와 최종 q99를 적합한다. 제외한 정상 영상은 어떤 reference나 threshold에도 넣지 않고 평가에만 쓴다. 일부 branch만 제외하는 불완전한 holdout을 하지 않는다. FIT 특징 학습에 이 4개 영상이 들어가지 않았는지도 provenance로 확인한다.
3. 기존 설정 10(체류 없음), 11(상태별 체류), 12_support(동일 support 대조), 12(진입별 체류)를 그대로 비교한다. 모델·threshold를 고르거나 새 CDF/가중치를 탐색하지 않는다. FIT 모델과 정상 fold 입력·출력을 저장해 재현한다.
4. 제외 영상별 원본 프레임 오탐률, sampled 오탐률, q99, reference/support와 fallback 빈도, 맥락별 정상 꼬리를 기록한다. 전체 프레임 가중 오탐률과 영상별 오탐률 평균을 구분한다. 4개 영상의 작은 표본에서 통계적 유의성을 주장하지 않는다.
5. 이번 평가는 정상 영상만 사용하므로 이상 AUROC/AP·recall·이상 구간 지연은 계산 대상이 아니다. 기존 테스트 결과를 새 실험 결과로 재포장하지 않는다. 새 테스트 평가 없이 보정 안정성의 근거를 먼저 확보한다.
6. 원본 시퀀스 그룹 독립성은 알려져 있지 않다. 따라서 이는 고정 FIT에 대한 정상 calibration 영상 단위 검증이며 전체 IPAD 일반화나 최종 논문의 독립 테스트를 대체하지 않는다.

실험 결과를 보고 다음 추천순 3개를 갱신한다. 정상 보정이 안정적이면 의미/관측 문제를, 불안정하면 정상 데이터 지원과 보정 구조를 우선 검토하되 후속 설계를 지금 확정하지 않는다.
